## 🚀 Setup in 4 Steps

1. **Import** the workflow JSON into N8N
2. **Connect** Google Sheets + LinkedIn credentials
3. **Add** your Gemini API key (free at aistudio.google.com)
4. **Add topics** to Google Sheet & activate workflow!
